Polylog UI Map

Every part of the Polylog panel, with the name we'll both use for it. Say "Repo List row" or "Log toolbar" and we mean the same thing.

Click any box, number or name to copy the name. Each red box is one named region, and its red number points to the name below. Boxes inside boxes are parts of a bigger region (the Filter bar sits inside the Log view). The Log and Compare each use one native surface; their headings are labels, not full-row collapse controls. The mocks scroll sideways on a narrow screen.

1Polylog panelThe "Polylog" tab in VS Code's bottom panel. Holds every Polylog view.
2Log viewThe merged history of every repository. Everything on its left side, down to the footer, belongs to it.
3Log toolbarFixed, explicit buttons: repository grouping, Compare, Uncommitted sidebar, Fetch All, side-by-side/stacked layout, and the pull/profile menu. Clicking blank title space has no fold action.
4Repo ListThe list of repositories on the Log's left. Tick to choose which repositories the Log shows. Today's name in the code is "Repositories pane".
5Repo search"Filter repositories": narrows the Repo List by name.
6All repositories rowTicks or unticks every repository; shows how many are picked.
6aProfile rowA saved group of repositories (polylog.profiles). Click: tick exactly them; highlighted while the ticks are that profile. ⚠ when some are not in this workspace. Right-click: Show, Update to Current Selection, Rename…, Delete. ⋯ → Switch Profile… does the same with the Repo List hidden.
6bSave as profile row"＋ Save as profile…": shown while the ticked repositories are neither All nor a profile. Click to name them. Right-click a repository for Profiles… (which profiles it is in).
7Sync badge↓ commits to pull, ↑ commits not pushed, as of the last fetch.
8Repo List rowOne repository: checkbox, color dot (same color as its chip in the Commit list), name. Right-click for the Repo menu.
9Filter barThe boxes above the commits. Every filter runs inside git.
10Search boxOrdinary text matches messages across selected repositories; full or 7+ character hashes locate commits directly. sha: accepts 4+ hexadecimal characters; other filters are temporarily ignored during lookup.
11Author boxSearchable multi-select checklist, with the Me toggle and each repository's own identity.
12Path boxCommits that touched a file, folder or glob.
13Branch boxAll local and remote branches by default. Search and select several names; Git returns their union. A repository without any selected branch is skipped, not replaced with its current branch.
14Date range24 hours, 7 days, 30 days, all time, or custom.
15Refresh buttonReads every repository again.
16Commits | Uncommitted switchAt the top of the Log. Its badge counts the uncommitted files in the ticked repositories. Uncommitted shows one Uncommitted list row per repository with work (files, change meter, staged/new tags, when edited); clicking one shows its files in the Changes view. Right-click a row or the Changes view root for Commit…, Stage All, Unstage All and Discard All Changes; a file or folder there for Stage, Unstage and Discard. Several selected rows act together.
17Commit rowRepository band, real parent graph, subject, compact branch/tag references, author and date. Explicit graph controls fold complete linear histories; selection keeps real commit ids.
18Load moreThe next page of commits.
19Log footerThe selected date/topology order, branch-scope coverage, folded count and commit count.
20Changes viewIntegrated changed-file region with its own toolbar, file search and independent scrolling. It can also open as a movable editor tab.
21Commit detailsFull message below the files, preserving paragraphs/trailers, author/email/time/hash, colored refs and containing branches. Drag its divider to resize; only its small arrow collapses it.
22Folder rowA folder, with how many changed files it holds.
23File rowA changed file: +/− lines and its A/M/D/R badge. Click opens the diff.

37Selected Commit rowsCtrl/⌘-click adds or removes a commit, Shift-click (or Shift+↑/↓) selects a range, in any repositories. The focus row has the active color, the others the inactive one. Two or more put the Changes view in Combined Changes; a plain click goes back to one.
38Selection limit noticeIn the Log footer when a click would select more than 100 commits (the click is refused).
39Clear SelectionIn the Changes view's title while several commits are selected: back to the focused commit alone. All Files is hidden meanwhile.
40Combined repository rowOne per repository with selected commits, in its Repo List color; the tooltip lists its selected commits.
41Combined File rowEach changed file once: the selected commits that touched it, and its net A/M/D/R badge. Its diff shows only what those commits did (other commits' lines as context). ⚠: an unselected commit edited the same lines, so the diff runs from before the first to after the last; the tooltip and the diff title name it.
42No net change rowFiles added and removed again, or changed and changed back, within the selection: named here instead of listed.

27Uncommitted viewIn the Polylog side bar (the Polylog icon in the Activity Bar, like Source Control): one row per ticked repository with uncommitted work. Hover a row: ✓ Commit… on a repository (right-click it for Stage All, Unstage All and Discard All Changes); ↶ Discard and − Unstage on staged rows; ↶ Discard and + Stage on changes. Discard always asks first. Each file opens the diff Source Control would.
29All Files toggleChanges toolbar: switch all/changed files, clear a combined selection, expand/collapse all, copy commit data or open Changes independently.
30Staged groupAnd its sibling, the Changes group: what is staged and what is not, under each repository of the Uncommitted view. A file staged and changed again is in both.
28Polylog Compare tabA panel tab next to Polylog (⇄ in the Log toolbar, or the Command Palette): Repositories · Left · Right, side by side; a file opens its diff in the editor area above.
31Compare toolbarBranch pickers, swap, Files/Commits, refresh, shared-file filtering, layout, side visibility and Close. All original commands remain reachable.
32Branch pickerOpens under a branch box: a search box over Recent pairs, Favorites ★, Local and Remote, each name "in N repositories".
33Compare repository rowOne per ticked repository whose files differ: its Repo List color and name (commit counts in the tooltip); "no common history" or "git error" when it cannot be compared. ▸ unfolds the changes committed on both sides. Selecting it fills Left and Right. Right-click: the repository menu.
34Left and Right viewsTwo resizable regions within one Compare surface. Folder/commit text selects a row; only the small arrow or a keyboard action folds it. Both sides retain display mode, shared-file filtering, expand/collapse, Show More and file/commit context menus.
35On both duplicatesUnder a Repositories row (its ▸): each change committed on both sides (cherry-picked), with both commit ids.
36Missing a branchMissing repositories are listed separately. Its small arrow expands the names; the heading text and right-hand blank space do not.

Version 1.4 interaction contract

Exists
Changed-file searchMatches filenames, full paths and rename sources. Enter opens the first match; Escape clears. Matching ancestors remain visible and bulk actions cannot include hidden children.
Layout and fold controlsLog/Changes and Compare support remembered sizes and side-by-side/stacked layouts. Section titles and their blank space do not collapse any view. Folder, commit, duplicate and missing-repository disclosure use their own arrow controls.
Branch sidebarLocal/remote grouping, search, favorites and explicitly scoped Git actions; selecting a ref for history does not check it out.
Language and themesEnglish and Simplified Chinese follow the editor language. All colors/fonts follow the editor theme, including both high-contrast variants.
