# Linyra 1.4.2 设置与特色演示工作日志

日期：2026-10-28（Asia/Singapore）

## 最终需求

公开配置改用自己的 `linyra.*` 名称，且用户明确要求旧设置不用迁移。
介绍需要实际展示 Linyra 相对继承功能的新增与改进，不能只复用通用跨仓库搜索演示。

## 配置与运行逻辑

- package.json 仅注册六项 `linyra.*` 设置，不保留 `polylog.*` 别名或弃用项。
- 分页、并发、发现深度、排除规则、配置组和行归属的真实读取均切换到新配置段。
- 仓库发现／配置组与行归属的配置变更监听使用新名称。
- 配置组保存、成员变更、排除仓库及撤销均写入 `linyra.*`，保留原有设置作用域和错误处理。
- 空仓库提示、排除提示、中英文设置说明和 README 同步更新。
- 不增加配置迁移器、旧名称回退读取或启动时的设置写入；现有用户文件保持原样。
- 保留原命令、视图、URI、面板状态标识以及全部工具栏入口；不改功能颜色和已确认图标。

## 真实素材

录制脚本增加 `--features` 模式，在独立 Git HOME、编辑器 profile 和示例工作区中运行生产 webview。
主窗口保持此前确认的编辑器／日志比例；功能片段从真实窗口裁出对应区域，不拉伸、不重画。

- `feature-branches.gif`：真实分支轨道、分支与作者多选、日期／拓扑排序、折叠与展开。
- `feature-commit-review.gif`：正文、共同作者、多色引用与图标、包含分支、显隐、实际拖动分隔线、文件搜索。
- `feature-hash-lookup.gif`：默认时间范围下查找旧提交，清空哈希后恢复。
- `feature-compare.gif`：文件／提交、展开、切换仓库、交换与实际拖动左右分隔线。
- 静态图保留复选框、折叠汇总、作者选择、提交详情、哈希提示与比较面板，便于逐帧复核。
- README 的首屏和各功能段落使用对应片段，并说明具体操作；分支侧栏也实际嵌入截图。

素材放入 `media/v1.4.2/`，不覆盖 1.4.1 图片。原始帧和调试文件继续留在忽略目录。
开发录制工具及图片不进入 VSIX，也不增加运行时依赖。
