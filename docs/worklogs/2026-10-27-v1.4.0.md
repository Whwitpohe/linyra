# Polylog 1.4.0 工作日志

日期：2026-10-27（Asia/Singapore）

基线：1.3.1 / `c1f7209`
发布目标：当前 Git 远端所指向的个人仓库；安装包沿用现有扩展 ID，保留用户设置。

## 需求与问题

本轮围绕多仓库日常查提交、读提交说明和分支比较展开。原更改区把提交标题、作者、哈希和时间挤在一行，长说明只能悬停查看；原生视图标题的整行点击都能折叠，右侧空白也会误触。布局迁移后，需要完整保留旧工具栏、文件／提交切换及各类右键操作，不能用减少功能的方式解决误触。

同时补齐已明确提出的能力：默认全分支和多分支筛选、提交列表分支标签、真实多轨道提交图、日期／拓扑排序、哈希定位、当前更改文件筛选，以及简体中文支持。

## 主要实施内容

### 1. 提交详情与更改文件

- 将完整提交说明移到文件列表下方，保留段落、换行和共同作者等 trailer。
- 单独展示作者、邮箱、完整日期时间、短哈希及仓库标记；支持复制完整哈希、复制完整说明和在远程打开。
- 显示实际指向该提交的 HEAD、本地／远程分支和标签，区分颜色和图标；另外列出包含此提交的分支，支持展开、收起。
- 提交详情支持独立滚动、拖动调节高度、双击重置和小箭头折叠；保存高度及折叠状态。
- 更改文件的增删数量右对齐。根据用户修正，文件名、旧路径及数量继续沿用原有 Git 状态颜色，未将旧路径单独灰化。
- 增加当前更改文件搜索：文件名、完整路径、重命名前路径均可匹配，支持大小写不敏感和 Windows 路径分隔符。
- 匹配时保留目录层级、显示匹配数量；Enter 打开首个匹配的 Diff，Escape 清空，清空后恢复原目录折叠状态。
- “全部文件”模式的搜索使用完整的更改列表，不依赖文件夹是否已在界面展开。

### 2. 日志图、筛选与定位

- 分支筛选默认覆盖所有本地和远程分支，改为可搜索多选下拉；清空选择恢复全部分支。
- 多选分支在 Git 查询中求历史并集，共同祖先只显示一次；所选分支不存在的仓库被跳过，并在页脚说明。
- 作者改为可搜索多选下拉，保留“我”和仓库各自的 Git 邮箱语义。
- 提交图根据真实父提交建立边，同仓库并行分支使用不同轨道和颜色；仓库身份参与节点键，避免跨仓库误连。
- 提交行显示实际 Git 引用；本地和对应远程分支共用紧凑标签，例如 `origin & main`。
- 提供按提交日期和拓扑方式排序。拓扑分页维持每个仓库的父子顺序，合并支路不会被时间戳打散；跨仓库仍按可用头部提交合并。
- 提供完整线性历史段折叠；保留分支头、标签、分叉、合并和未知父节点，不伪造连接；显式工具栏可全部展开、折叠。
- 现有搜索框支持完整哈希和至少七位短哈希；`sha:` 可显式使用 Git 支持的四位以上前缀。
- 哈希由 Git 对象数据库解析，并批量确认对象类型；只返回提交，排除 blob 和标签对象本身；有歧义时列出所有候选。
- 哈希定位限定在所选仓库内，临时忽略日期、作者、分支和路径条件并在界面提示；清空后恢复原条件。
- 哈希查询不进行全历史扫描；Git 批处理输入走标准输入，不拼接 shell 命令，候选对象分批读取以兼顾 Windows 参数长度。

### 3. 防误触布局与功能保留

- 日志／更改合为一个原生承载视图，取消能把整个日志收起的原生标题行。
- 日志与更改支持左右／上下布局、拖动、大小记忆和独立显示／隐藏；可在编辑区独立打开更改页。
- 补齐原日志工具栏全部十三个命令入口：仓库分组、比较显示／隐藏、未提交侧栏显示／隐藏、获取状态、获取／拉取、落后仓库筛选和仓库配置。
- 更改区保留并明确展示：清除多选、全部／更改文件切换、展开全部、折叠全部，以及复制／远程打开／独立打开菜单。
- 分支比较也改为一个原生承载视图，内部保留仓库列表和左右比较区；标题文字和空白均不再承担折叠动作。
- 保留比较的文件／提交切换、分支选择、交换、刷新、收藏、最近使用的分支对、重复提交和缺少分支信息。
- 保留左右侧显示／隐藏、展开／折叠、加载更多、隐藏相同文件、状态徽标及重命名路径；布局、分隔线位置和侧栏状态可保存。
- 文件、提交、缺少分支列表等折叠动作限于小箭头或明确键盘动作，标题和普通行文字仅选中。
- 保留原右键能力：打开工作区文件、文件历史、复制路径、复制提交信息、远程打开、与分叉点比较，以及未提交文件的暂存／取消暂存／放弃操作。
- 主更改页与独立更改页分别保存选择；过滤后的文件夹不能触发包含隐藏子文件的整体修改，多选操作仅作用于匹配文件。
- 保留旧侧栏焦点／隐藏命令的兼容入口，并为 webview 操作增加当前行身份校验，拒绝伪造或过期的行参数。

### 4. 分支侧栏与本地化

- 增加本地／远程分支树、分支搜索、收藏、分组展开状态和仓库范围管理。
- 分支右键支持查看历史、比较分支或工作区、检出、新建、重命名、获取、拉取、推送、合并、变基、工作树及删除。
- 操作由完整仓库／引用身份限定；删除保持非强制保护，跨分支操作使用明确目标，必要确认和 Git 自身检查继续生效。
- 扩展命令、原生菜单、提示、错误和 webview 文案接入简体中文；缺失或其他语言回退英文。
- 提交说明、仓库名、文件路径和分支名保持原始文本，通过文本节点和转义传递，避免被解释为 HTML 或占位符。

## 兼容性说明

默认分支范围从当前分支改为全部本地／远程分支；已明确保存的分支选择继续有效。原生可折叠小视图的位置由面板内布局替代。未提交内容仍保留独立侧栏，Diff 继续在编辑器中打开。读取、搜索和图形折叠不修改 Git 仓库；写操作必须由用户明确触发。
