# Linyra 1.4.1

本版更新商店介绍、英文／中文使用说明和演示素材，让安装前看到的内容与当前 Linyra 一致。
功能保持 Marketplace 1.4.0 的实现，已确认的图标、Git 状态颜色和原有命令入口不变。

## 更新内容

- **重新录制真实界面。** GIF 展示一次搜索串起四个仓库的相关提交，并切换前端与 API 的原生 Diff。
  静态图补齐真实分支轨道、多分支选择、完整提交说明、文件历史及分支比较。
- **调整展示比例。** 使用最大化的真实 VS Code 窗口，上方编辑器与下方约 46% 的日志区各有实际内容。
  提交说明另配清晰局部图；分支比较左右区域均衡，保留底部状态和完整右边界。
- **重写双语介绍。** 明确默认“全部分支／最近 24 小时”，说明作者与分支多选、日期／拓扑排序、
  哈希定位、文件搜索、可拖动的说明区域、未提交改动、仓库配置组和原有工具栏操作。
- **更新安装路径。** README 链接到已公开的 Marketplace 扩展；中文说明随安装包提供。
  Open VSX 尚未完成发布，使用该注册中心的编辑器可先从 GitHub 下载 VSIX。
- **保留可复现的素材流程。** 使用隔离的示例仓库、Git 配置和 VS Code 配置录制；示例含真实分叉、
  合并和发布分支差异。开发录制脚本、截图、原始帧与依赖不进入运行时包。

## 升级与兼容

已安装 Marketplace 版本的用户可正常升级。首次从 Polylog 切换时，请禁用或卸载
`lntvan166.polylog-git`，只启用 `whwitpohe.linyra`，再重新加载窗口。
现有 `polylog.*` 设置、命令和快捷键保持兼容；不同扩展 ID 的私有面板状态分别保存。

旧 `v1.4.0` 标签、历史 Polylog 包和校验值不替换。本版安装包为
`whwitpohe.linyra-1.4.1.vsix`，对应新的 `v1.4.1` 源码标签；SHA-256 见附件 `SHA256SUMS.txt`。

## 安装

Marketplace 扩展 ID：`whwitpohe.linyra`。

```powershell
code --install-extension whwitpohe.linyra --force
```

手动安装本 Release 的包：

```powershell
code --install-extension .\whwitpohe.linyra-1.4.1.vsix --force
```
