# Linyra 1.5.0

本版把 Linyra 做成 JetBrains IDE（WebStorm、IntelliJ IDEA）Git 工具窗口里 Log 那样的多仓库 Git 客户端：
合并日志仍是核心，日常的仓库操作从它所在的那一行发起，并且只在那一行的仓库里执行。

## 跨仓库操作

- **跨仓库分支操作…：** 在所有勾选的仓库中签出、新建或合并同名分支。
- **推送…：** 一个对话框列出每个仓库待推送的提交和目标分支，勾选后一起推送。
- **更新项目：** 先获取全部，再把每个仓库合并或变基到上游。不自动储藏：有本地改动挡路的仓库会被跳过并列出名字。
- 日志获得焦点时可用 JetBrains 的快捷键：Ctrl+T（更新项目）、Ctrl+Shift+K（推送…）、Ctrl+Shift+`（跨仓库分支操作）。

## 提交与引用

- 右键提交：优选、还原、将当前分支重置到此处、签出此修订、在此处新建分支或标签。
  当前签出的提交还可以撤销提交、编辑提交信息；提交已推送时会先提醒。
- 右键落在多选范围内时，优选和还原作用于所有选中的提交（优选从最旧的开始）。
- 仓库树中每个仓库展开为“本地／远程／标签／储藏”。标签可以分离签出、推送和删除；
  储藏可以查看更改、应用、弹出和删除；仓库行上有“储藏更改…”。日志的分支筛选也能选标签。
- 搜索框新增“区分大小写”和“正则表达式”；无效的表达式按普通文本搜索并标出。
- ⋯ 菜单新增视图选项：高亮我的提交、高亮当前分支、显示哈希列。

## 界面

- 日志顶部合成一行：提交／未提交切换、筛选和操作按钮，面板窄时才折成两行。
- 仓库与分支合成一棵树，带“全部展开／全部折叠”，搜索也能找到分支名。
- 未提交改动只在日志的“未提交”一侧查看，独立的 Linyra 侧栏已移除。
- 所有图标改用 VS Code 自己的 Codicon；重复的按钮已去掉；仓库色带更浅。
- 配置组在中文界面里改称“仓库组”。

## 修复

- 同一秒内的提交保持 git 的顺序：子提交不会再排到父提交下面，批量优选也不会因此反着应用。
- 比较页面按日志的颜色标识每个仓库。
- 在仓库搜索框里打字时，仓库颜色不再变化。

## 性能

- 滚动时复用行，每帧约 9 ms 降到 1.5 ms。
- 深度翻页时每个仓库的批量逐步加大：在 10 万提交的仓库里翻到第 2 万行，git 调用从 100 次减到 14 次。
- 拓扑排序慢时提示可以写入 commit-graph（只提示，不会自动写）。
