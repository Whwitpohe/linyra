# Linyra 1.4.2

本版让设置使用 Linyra 自己的名称，并用专门的真实界面录制介绍新增与改进功能。

## 设置使用自己的命名空间

六项公开设置统一改为：

| 设置 | 默认值 | 用途 |
| --- | --- | --- |
| `linyra.pageSize` | `200` | 每仓库每页提交数 |
| `linyra.maxConcurrency` | `16` | Git 并发数上限 |
| `linyra.scanDepth` | `2` | 仓库发现深度 |
| `linyra.excludeRepos` | `[]` | 排除仓库的模式 |
| `linyra.profiles` | `{}` | 仓库选择配置组 |
| `linyra.blame` | `true` | Diff／历史版本的行归属 |

设置页、实际读取、变更监听、配置组保存、排除与撤销、提示文字及双语文档都使用新名称。
按维护者要求，不迁移、不读取、不注册旧 `polylog.*` 设置，也不自动改写现有配置文件。
如需自定义，请在 `linyra.*` 下重新设置；未设置时使用上表默认值。

命令、视图和 URI 标识继续兼容，原有快捷键与功能入口保留；图标和主题配色不变。

## 专门介绍 Linyra 新增与改进

本次不是再放一段通用的跨仓库搜索，而是四段独立 GIF 与对应截图：

1. **真实多分支图：**分支／作者搜索多选、日期与拓扑排序、线性历史折叠及展开。
2. **提交审阅：**完整正文与尾注、彩色 HEAD／本地／远程／标签、包含分支、说明显隐、真实拖动分隔线和文件搜索。
3. **旧提交定位：**粘贴短哈希，在最近 24 小时的筛选下定位三个月前的提交，清空后恢复原筛选。
4. **稳定的分支比较：**文件／提交切换、展开提交文件、选择仓库、左右交换及实际拖动左右分隔线。

分支侧栏另外展示本地／远程分支搜索。中英文介绍均说明录制中的动作，区分继承的合并时间线与 Linyra 的改进。
素材来自隔离示例仓库与真实生产界面，不用仿图，不改编辑器颜色；录制工具和图片不进入安装包。
