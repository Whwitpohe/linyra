# Polylog v1.4.0

本次升级集中解决多仓库查提交时的阅读效率、筛选能力和面板误触，并补齐简体中文和分支操作。

## 最重要的变化

- **日志和分支比较不再因点击标题右侧空白而整块折叠。** 日志／更改与比较三区各自使用稳定的面板；内部折叠由小箭头或明确键盘动作控制。
- **完整提交说明有独立区域。** 正文保留段落和共同作者信息，作者／邮箱／时间／哈希独立展示，分支引用和包含此提交的分支可直接查看。区域可拖动、折叠并记住大小。
- **默认全分支，分支和作者均可搜索多选。** 多分支结果取并集，共同提交不重复；清空分支选择恢复全部本地／远程分支。
- **真实多轨道提交图与两种排序。** 支持按提交日期或拓扑方式查看历史，保留真实分叉／合并关系，避免不同仓库误连，并可折叠长线性历史段。
- **新增哈希定位和更改文件内搜索。** 在顶部粘贴完整或至少七位哈希即可定位旧提交；在文件区输入名称、路径或重命名前路径即可缩小当前更改列表。
- **简体中文与分支侧栏。** 命令、菜单和提示随 VS Code 语言切换，分支树提供搜索、收藏、查看历史和明确仓库范围的 Git 操作。

## 旧功能保留情况

日志工具栏保留仓库分组、分支比较、未提交侧栏、获取／拉取、落后仓库筛选及仓库配置。更改区保留全部文件切换、多选、展开折叠、复制和独立打开。分支比较保留“文件／提交”、分支选择、左右交换、刷新、收藏、最近使用、相同内容过滤、加载更多及原有右键菜单。

所有 Diff 仍使用 VS Code 原生编辑器，交换或选择分支后继续跟随正确左右版本；重命名路径和 Git 状态颜色继续保留。

## 如何使用

1. 搜索框继续按提交标题和正文匹配普通关键词；输入完整或至少七位十六进制哈希进入定位模式。需要更短的前缀时使用 `sha:abcd`。
2. 哈希定位在所选仓库内临时忽略其他筛选，界面会提示；清空搜索立即恢复之前的条件。
3. 更改文件搜索支持名称、完整路径和旧路径；Enter 打开首个匹配 Diff，Escape 清空。在“全部文件”模式下搜索的是该提交的更改文件。
4. 日志和比较的布局按钮可切换左右／上下排列，分隔线可拖动，各区可独立显示、隐藏和滚动。
5. 分支比较顶部“文件／提交”切换仍在；相同内容过滤及每侧的展开／折叠按钮也保留。

## 升级注意

- 日期默认仍是最近 24 小时，分支默认范围改为全部本地／远程分支。已有明确分支选择会保留。
- 原生小视图的旧位置由面板内布局替代，首次升级可重新拖动到习惯的大小。
- 读取历史、搜索和折叠不写仓库。检出、推送、合并、删除等 Git 写操作仅在明确选择对应命令时执行，并继续接受必要检查和确认。
- 沿用原扩展 ID，升级后保留设置。本版本通过本仓库的 GitHub Release 提供 VSIX，未向 Marketplace 或 Open VSX 发布。

## 安装

下载本 Release 附件 `polylog-git-1.4.0.vsix`，在 VS Code 中执行“扩展：从 VSIX 安装”，或运行：

```powershell
code --install-extension .\polylog-git-1.4.0.vsix --force
```

安装完成后执行“开发者：重新加载窗口”。附件校验值见 `SHA256SUMS.txt`。
